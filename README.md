# Ironlog: a Gym Tracker vibe-coded by Claude Opus 5.5

ETH Zürich had a good workout tracker that was a bit too cluttered in terms of the number of exercises.
This is a streamlined clone of that app, 100% vibe-coded by Claude.

I first prompted Claude in Figma to create a gym tracker app with a few requirements and then pulled the code down and fed it to Claude Code
telling it to build a Jetpack Compose Android app and it oneshotted this.

## Features

- Workout presets
- Support for many exercises
- Weights in lb/kg, drop down for selecting dumbbells, barbells, cable, or smith machine, and toggle for per side or both side
- Workout history obviously, persisted
- There's a timer in there somewhere apparently as well
